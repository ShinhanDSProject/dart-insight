# ADR-0018: 차트는 라이브러리 없이 HTML·CSS 컴포넌트로 그린다

- 상태: 채택
- 결정한 날: 2026-10-23
- 관련: [#189](https://github.com/ShinhanDSProject/dart-insight/issues/189), 노션 기능 기획서 FS-3 '재무 수치 변화 차트'

## 맥락

- 재무 탭(W-03 ②)에 증감이 큰 계정을 보여 줄 차트가 필요하다(FS-3). 지금 필요한 모양은 두 가지다: 0을 가운데 둔 가로 막대(증감률)와 이전 → 현재 덤벨(금액).
- 차트의 막대는 표의 행과 같은 일을 한다: 누르거나 Enter로 수치 근거를 연다(AGENTS.md '화면의 수치는 근거 위치를 가짐'). 키보드·스크린리더 사용이 표와 같아야 한다.
- 색·글꼴·간격은 `frontend/src/shared/styles/tokens.css` 토큰만 쓴다(conventions UI-2). 증감에 빨강·초록을 쓰지 않는다(`frontend/design-system.md` 3-3).
- 축은 하나다. 계정마다 금액 규모가 수천 배 달라 두 축이나 계정별 축을 쓰면 잘못 읽힌다.

## 결정

- 차트는 차트 라이브러리 없이 React 컴포넌트와 CSS로 그린다. 막대·점의 위치는 순수 함수(`features/analysis-result/model/chart.ts`)가 % 값으로 계산하고, 각 계정 행은 `<button>`이다.
- 차트에 쓸 계정 고르기(증감액 절댓값 상위 10개, 계산 불가 제외)도 같은 순수 함수가 하고 vitest로 확인한다. 응답 값을 정렬·고르기만 하고 새 숫자를 만들지 않는다.
- 차트 색은 토큰(`--color-chart-previous`, `--color-chart-current`)으로 두고, 색 검사 스크립트로 밝기 범위·채도·색맹 구분(ΔE ≥ 8)·배경 대비(3:1)를 확인한 값만 쓴다.
- 다른 화면에서 같은 모양이 필요해지면 `shared/ui`로 올린다(conventions UI-3).

## 검토한 다른 방법

| 방법 | 고르지 않은 이유 |
| --- | --- |
| Recharts | SVG 안 막대를 버튼처럼 쓰려면 커스텀 모양·키보드 처리를 다시 짜야 한다. 번들이 100KB 넘게(gzip) 늘어 지금 앱(약 128KB)의 두 배 가까이 된다 |
| visx | 저수준이라 결국 축·막대를 직접 짠다. 의존성만 늘고 토큰 적용은 같은 일이다 |
| Chart.js | canvas라 막대에 포커스·aria를 줄 수 없고 근거 열기를 표와 같게 만들기 어렵다 |

## 결과

- 좋아지는 점: 번들이 늘지 않는다. 막대가 버튼이라 키보드·스크린리더·근거 열기가 표와 같다. 색·글꼴이 토큰을 그대로 따른다.
- 감수하는 점: 축 눈금·툴팁을 직접 만든다. 선 그래프·시계열처럼 모양이 늘면 일이 커진다.
- 지켜야 할 것: 축은 하나만 쓴다. 증감은 막대 방향과 ▲▼·부호로 보이고 색에 의존하지 않는다. 없는 값(null)은 0으로 그리지 않는다.

## 다시 볼 때

- 시계열(세 보고서 이상)·선 그래프·여러 차트 종류가 필요해질 때
