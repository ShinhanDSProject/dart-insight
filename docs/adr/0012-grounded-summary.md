# ADR-0012: 요약은 코드가 고르고 사실 문장을 쓰며, LLM 문장은 근거·숫자를 검증한 것만 내보낸다

- 상태: 채택
- 결정한 날: 2026-10-22
- 관련: [PR #107](https://github.com/ShinhanDSProject/dart-insight/pull/107)(3.2), [PR #109](https://github.com/ShinhanDSProject/dart-insight/pull/109)(5.6), 노션 결정 로그 [초기 구상의 MVP 기능 포함 여부](https://app.notion.com/p/400b6afffc6f81e89598c2ea8630642b)(인용 검증은 확장 1순위), 노션 개발 기준 8장

## 맥락

- 이 서비스는 투자 조언이 아니고, 화면의 모든 문장에 근거 위치가 있어야 합니다.
- LLM은 숫자를 계산하거나 바꿔 쓰고, 원문에 없는 설명을 만들 수 있습니다.
- AI가 만든 문장에는 'AI 생성' 표시를 붙이고 모델·프롬프트 버전·호출 시각을 남겨야 합니다(AI 기본법 생성물 표시).
- 인용이 주장을 실제로 뒷받침하는지 판정하는 인용 검증은 MVP에서 빼고 확장 1순위로 뒀습니다.

## 결정

- 요약할 변화는 backend의 `SummarySelector`가 규칙으로 고릅니다(재무 수치 손익계산서 3개·재무상태표 2개, 문장 변화는 우선순위 높음·중간 상위 5개, 설명 후보는 현재 보고서의 경영진단·사업의 내용 문단 중 계정 이름이 나오는 앞의 2개).
- 재무 수치의 사실 문장은 backend의 `FinancialFacts`가 코드로 씁니다. 숫자는 계산한 값을 그대로 쓰고 '늘었어요·줄었어요'로만 적으며 좋고 나쁨을 평가하지 않습니다.
- LLM(ai-server `app/summary`, `PROMPT_VERSION` 지금 `summary-1`)은 두 가지만 씁니다: 문장 변화가 무엇인지 한 문장, 재무 수치에 대해 공시에 적힌 회사 설명 한 문장. 설명 후보가 없거나 LLM이 설명이 없다고 하면 '확인된 설명 없음'입니다.
- ai-server는 결과를 검증합니다: 근거 ID가 넘겨준 후보 위치 안에 있는지, 문장의 숫자와 크기 표현이 인용한 원문에 그대로 있는지, 투자 권유성 표현이 없는지([ADR-0013](0013-expression-check-gate.md)). 실패하면 문제를 알려 주며 최대 2회 다시 생성하고, 통과한 항목은 다음 생성에서도 유지합니다. 끝내 실패한 항목만 '검토 필요'입니다.
- backend는 ai-server 응답을 다시 확인합니다. 근거 ID가 없거나 요청한 위치가 아니면 그 항목을 '검토 필요'로 저장합니다. ai-server·LLM을 부를 수 없으면 분석을 실패로 끝냅니다.
- 'AI 생성' 표시는 화면이 문구로 판단하지 않고, 응답의 `aiGenerated` 값으로 코드가 붙입니다. 모델·프롬프트 버전·생성 시각과 LLM 호출 기록을 분석과 함께 저장합니다.

## 검토한 다른 방법

| 방법 | 고르지 않은 이유 |
| --- | --- |
| 재무표·원문을 통째로 LLM에 주고 요약하게 하기 | LLM이 숫자를 계산하고 근거를 지어냅니다. 무엇을 요약했는지 재현할 수 없습니다. |
| 검증 없이 내보내고 면책 문구만 붙이기 | 근거 없는 문장을 화면에 보이지 않는다는 원칙에 어긋납니다. |
| 인용 검증(NLI·LLM 판정)까지 MVP에 넣기 | 일정상 확장 1순위로 미뤘습니다. 지금은 근거 ID·숫자·표현을 코드로 확인합니다. |

## 결과

- 좋아지는 점: 재무 수치와 증감은 모두 코드가 계산한 값이고, AI 문장의 숫자는 인용한 원문에 있는 것만 허용합니다. AI 문장은 저장된 원문 위치를 근거로 가집니다. 검증에 실패한 문장은 보이지 않고 '검토 필요'로 남습니다.
- 감수하는 점: 요약이 짧고 기계적입니다. 근거 문단이 주장을 실제로 뒷받침하는지는 아직 확인하지 않습니다. 숫자 검사는 글자 비교라 원문 표현을 바꿔 쓴 맞는 문장도 막을 수 있습니다.
- 지켜야 할 것: 프롬프트·검증 규칙을 바꾸면 `PROMPT_VERSION`과 backend `Analysis.CURRENT_VERSION`을 함께 올립니다([ADR-0014](0014-analysis-reuse-and-version.md)). LLM 입력에 계산을 맡길 값을 넣지 않습니다.

## 다시 볼 때

- 실제 LLM 제공자를 연결해 품질을 평가할 때(7.3)
- 인용 검증을 붙일 때
