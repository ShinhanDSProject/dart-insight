# ADR-0013: AI 문장은 화면에 내보내기 전에 규칙 기반 표현 검사를 거친다

- 상태: 채택
- 결정한 날: 2026-10-22
- 관련: [PR #108](https://github.com/ShinhanDSProject/dart-insight/pull/108)(5.5), 노션 결정 로그 [투자 권유성 금지 표현 기준](https://app.notion.com/p/400b6afffc6f81bab915c86bdd8183aa)(미결정), [MVP 대상 사용자와 검토·결재·게시 흐름 포함 여부](https://app.notion.com/p/400b6afffc6f8150adf0d97601d9745b)(결재는 확장), `docs/project-background-research.md`

## 맥락

- 투자 권유·자문으로 읽히는 문장(매수·매도 추천, 목표주가, 주가 예측, '저평가' 같은 가치판단)을 화면에 내보내면 안 됩니다.
- 사람이 검토·결재하는 흐름은 MVP에서 빼고, 자동 검사로 막기로 했습니다.
- LLM에 '권유하지 마라'고 지시해도 지켜진다는 보장이 없습니다.
- 공시 원문에는 '자기주식 매도', '주가 변동 위험', '투자 기회 모색'처럼 막으면 안 되는 말이 흔합니다.

## 결정

- ai-server의 `app/compliance/expressions.py`(`RULESET_VERSION`, 지금 `expr-1`)가 정규식 규칙으로 AI가 만든 문장(요약·설명)만 검사합니다. 공시 원문과 코드가 만든 사실 문장은 검사하지 않습니다.
- 규칙은 권유·예측의 꼴만 잡아, 공시에 흔한 말은 막지 않습니다. 막아야 할 문장과 허용할 문장을 테스트 예문으로 함께 관리합니다(`tests/test_expressions.py`).
- 걸린 문장은 내보내지 않고 '검토 필요'로 바꾸며, 걸린 규칙(`blocked_rules`)을 저장해 화면의 검토 필요 목록에 보여 줍니다. 요약을 다시 생성할 때 이 문제도 LLM에 알려 줍니다([ADR-0012](0012-grounded-summary.md)).
- 규칙 내용은 결정 로그 '투자 권유성 금지 표현 기준'이 정해지기 전의 잠정안입니다. 검사 관문의 위치와 방식은 이 ADR이, 무엇을 막을지는 결정 로그가 정합니다.

## 검토한 다른 방법

| 방법 | 고르지 않은 이유 |
| --- | --- |
| 프롬프트 지시만 하기 | 지켜진다는 보장이 없고, 어긴 문장을 알아낼 수 없습니다. |
| LLM 분류기로 검사하기 | 비용이 들고 결과가 매번 다를 수 있습니다. 검사하는 쪽도 같은 위험을 가집니다. |
| 사람이 결재한 뒤 게시하기 | MVP 범위에서 뺐습니다(확장 P2). |
| 화면 면책 문구만 붙이기 | 문장 자체를 막지 못합니다. 면책 문구는 이용 안내(5.6)로 따로 둡니다. |

## 결과

- 좋아지는 점: 권유성 문장이 화면에 나가지 않고, 왜 막혔는지 규칙으로 남습니다. 같은 문장은 늘 같은 판정을 받습니다.
- 감수하는 점: 규칙에 없는 표현은 지나갈 수 있고(미탐), 규칙이 넓으면 중립 문장도 막힙니다(오탐). 예문 테스트로 둘 다 관리합니다.
- 지켜야 할 것: 규칙을 바꾸면 `RULESET_VERSION`과 backend `Analysis.CURRENT_VERSION`을 함께 올리고([ADR-0014](0014-analysis-reuse-and-version.md)), 막을 예문과 허용할 예문을 테스트에 더합니다.

## 다시 볼 때

- 결정 로그 '투자 권유성 금지 표현 기준'이 정해질 때
- 실제 LLM 출력에서 오탐·미탐이 자주 보일 때
