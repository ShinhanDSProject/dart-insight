# 발표·시연 진행 점검표

발표(11/18)에서 발표 페이지와 시연 자동 진행(#967)을 쓰는 사람이 보는 한 장짜리 점검표입니다. 시연 데이터 고정·백업·복원은 [시연 데이터 관리 가이드](demo-data-guide.md)를 봅니다.

## 1. 전날까지: 실서비스가 시연할 수 있는 상태인지

| 확인 | 방법 | 안 되면 |
| --- | --- | --- |
| AI를 쓸 수 있다 | 실서비스 `/system/ai-usage`에서 최근 호출이 성공인지 보고, 분석 결과 화면의 AI 에이전트에 질문 하나를 보낸다 | 'AI 사용 한도에 도달…'이면 서버의 `deploy/ai.env`(제공자·모델·키)를 확인한다. 팀 결정은 anthropic / claude-haiku-5-5(ADR-0062·0063) |
| 시연 쌍이 데워져 있다 | 실서비스 `/?demo`를 Space로 끝까지 한 번 돌린다(아래 3장) | 4단계에서 새 분석이 1~2분 돌면 정상이다. 한 번 끝나면 발표 때는 저장된 결과로 바로 열린다 |
| 공시 분석 탭이 데워져 있다 | 4단계에서 열린 결과 화면의 '공시 분석' 탭을 한 번 연다(처음엔 수십 초) | 오류면 AI 상태부터 확인한다 |
| 발표 뒤 배포가 겹치지 않는다 | 발표 직전에는 main에 병합하지 않는다(병합하면 약 10분 뒤 서비스가 다시 뜬다) | — |

- AI 질문은 비로그인이면 같은 IP에서 하루 20번, 새 분석은 하루 10번입니다(ADR-0054·0056). 리허설을 여러 번 하면 로그인한 상태(100번·30번)로 합니다.
- 분석 방식(`Analysis.CURRENT_VERSION`)을 올리면 저장된 분석이 모두 '이전 분석 방식' 결과가 되어 다시 돌려야 합니다. 발표 전에는 올리지 않습니다.

## 2. 발표 직전: 브라우저

1. Chrome 창 하나, 탭 하나로 `https://dart-insight.shinhanacademy.co.kr/easter/three-weeks.html`을 연다.
2. `P`로 발표 모드, `F`로 전체화면, 필요하면 `M`으로 배경음악(표지·Preview 장에서만 나온다).
3. 키: `Space`·`→`·`PageDown` 다음 장, `←`·`PageUp` 이전 장, `Home`·`End` 처음·마지막 장, `N` 발표 대본, `Esc` 발표 모드 나가기(전체화면에서는 브라우저가 Esc를 먼저 받아 전체화면이 풀린다).

## 3. 시연: Preview 장에서 Space

Preview 장(닫힌 노트북)에서 `Space`를 누르면 노트북이 열리며 약 4.7초 뒤 같은 페이지 안에서 시연이 시작됩니다. 주소가 바뀌지 않아 전체화면이 유지됩니다. 전환 중과 시연 중에는 발표 키가 듣지 않습니다.

`Space`를 누를 때마다 한 단계씩 진행하고, 화면 아래 자막에 단계 번호와 설명이 보입니다.

| 단계 | 하는 일 | 말할 것 |
| --- | --- | --- |
| 1 기업 찾기 | 검색창에 '삼성전자' 입력 | 회사 이름·종목코드·초성으로 찾는다 |
| 2 보고서 고르기 | 최근 보고서와 1년 전 보고서가 골라진 모습 | 비교할 두 보고서를 알아서 고른다 |
| 3 비교할 수 있는지 확인 | 기간·재무제표가 맞는지 확인한 결과 | 맞지 않으면 분석하지 않는다 |
| 4 핵심 3줄 | 분석 실행 → 결과 요약 | 줄마다 근거가 붙는다 |
| 5 근거 확인 | 핵심 줄을 눌러 계산식과 원문 위치 | 원문 위치를 확인하지 못한 AI 문장은 보이지 않는다 |
| 6 재무 수치 | 계정별 증감 표 | 증감은 AI가 아니라 코드가 계산한다 |
| 7 바뀐 문장 | 바뀐 문장 카드 | 더해지고 빠지고 고쳐진 곳을 원문 위치와 함께 |
| 8 AI 에이전트 | '이번 변화를 3줄로 정리해줘' 질문 | 답마다 근거, 투자 조언은 하지 않는다 |
| 9 답의 근거 따라가기 | 답의 근거 번호를 눌러 보고서 위치로 | — |

마지막 단계 뒤 `Space` → '시연 끝' → `Space`를 한 번 더 누르면 앱 화면이 닫히고 노트북 뚜껑이 닫히며 Q&A 장이 나타납니다.

## 4. 시연 중에 생길 수 있는 일

| 상황 | 화면 | 할 일 |
| --- | --- | --- |
| 4단계에서 새 분석이 실패하거나 90초를 넘김 | 기업 화면으로 돌아가 '이미 분석한 비교'의 결과가 열린다 | 그대로 진행한다(맨 위에 '이전 분석 방식' 띠가 보일 수 있다) |
| 단계가 실패 | 자막에 사유와 'Space로 다음 단계로 넘어가요' | `Space`로 다음 단계 |
| AI가 답하지 못함(8단계) | 'AI가 이번에는 답하지 못했어요' | `Space` 두 번(9단계도 바로 넘어간다) |
| 직접 보여 주고 싶다 | 시연 화면에서 `Esc` → 오른쪽 아래 '발표로 돌아가기' 버튼만 남는다 | 직접 조작한 뒤 버튼을 누르면 Q&A 장으로 간다. 전체화면이면 Esc로 전체화면이 풀리니 `F`로 다시 켠다 |
| 화면이 새로 고쳐짐 | 자막이 'N단계부터 이어서 해요' | `Space`로 이어 간다 |

- 앱만 따로 열어 시연하려면 주소에 `?demo`를 붙입니다. `?demo=5`처럼 번호를 주면 그 단계부터 시작합니다.
- 리허설에서 실제 한글 입력으로 첫 화면 검색도 한 번 쳐 봅니다. 한 글자를 조합하는 도중에 0.3초 넘게 멈추면 그 글자의 조합이 끊길 수 있습니다(#988의 남은 한계).
