# 발표·시연 진행 점검표

발표(11/18)에서 발표 페이지와 시연 자동 진행(#967), 쉬는 동안 띄우는 대기 화면을 쓰는 사람이 보는 한 장짜리 점검표입니다. 시연 데이터 고정·백업·복원은 [시연 데이터 관리 가이드](demo-data-guide.md)를 봅니다.

## 1. 전날까지: 실서비스가 시연할 수 있는 상태인지

| 확인 | 방법 | 안 되면 |
| --- | --- | --- |
| AI를 쓸 수 있다 | 실서비스 `/system/ai-usage`에서 최근 호출이 성공인지 보고, 분석 결과 화면의 AI 에이전트에 질문 하나를 보낸다 | 'AI 사용 한도에 도달…'이면 서버의 `deploy/ai.env`(제공자·모델·키)를 확인한다. 팀 결정은 anthropic / claude-haiku-5-5(ADR-0062·0063) |
| 시연 쌍(삼성전자 반기보고서 2025.06 → 2026.06)이 데워져 있다 | 실서비스 `/?demo`를 Space로 끝까지 한 번 돌린다(아래 3장) | 4단계에서 새 분석이 1~2분 돌면 정상이다. 한 번 끝나면 발표 때는 저장된 결과로 바로 열린다 |
| 공시 분석 탭이 데워져 있다 | 4단계에서 열린 결과 화면의 '공시 분석' 탭을 한 번 연다(처음엔 수십 초) | 오류면 AI 상태부터 확인한다 |
| 발표 뒤 배포가 겹치지 않는다 | 발표 직전에는 main에 병합하지 않는다(병합하면 약 10분 뒤 서비스가 다시 뜬다) | — |

- AI 질문은 비로그인이면 같은 IP에서 하루 20번, 새 분석은 하루 10번입니다(ADR-0054·0056). 리허설을 여러 번 하면 로그인한 상태(100번·30번)로 합니다.
- 분석 방식(`Analysis.CURRENT_VERSION`)을 올리면 저장된 분석이 모두 '이전 분석 방식' 결과가 되어 다시 돌려야 합니다. 발표 전에는 올리지 않습니다.
- AI 한 줄 풀이를 새로 만드는 것도 하루 한도가 있습니다(비로그인 30번·회원 150번, ADR-0069). 이미 만든 풀이를 다시 보는 것은 세지 않습니다.

## 2. 발표 직전: 브라우저

0. 발표 30분쯤 전에 실서비스 `/?demo`를 한 번 더 끝까지 돌린다. 배포나 서버 재시작 뒤 첫 요청은 느릴 수 있다(2026-11-14 배포 직후 2단계가 한 번 80초 넘게 걸렸고, 다시 돌리니 3초였다).
1. Chrome 창 하나, 탭 하나로 `https://dart-insight.shinhanacademy.co.kr/easter/three-weeks.html`을 연다.
2. `P`로 발표 모드, `F`로 전체화면, 필요하면 `M`으로 배경음악(표지·Preview 장에서만 나온다).
3. 키: `Space`·`→`·`PageDown` 다음 장, `←`·`PageUp` 이전 장, `Home`·`End` 처음·마지막 장, `N` 발표 대본, `Esc` 발표 모드 나가기(전체화면에서는 브라우저가 Esc를 먼저 받아 전체화면이 풀린다).

## 3. 시연: Preview 장에서 Space

Preview 장(닫힌 노트북)에서 `Space`를 누르면 노트북이 열리며 약 6초 뒤 같은 페이지 안에서 시연이 시작됩니다. 주소가 바뀌지 않아 전체화면이 유지됩니다. 전환 중과 시연 중에는 발표 키가 듣지 않습니다.

`Space`를 누를 때마다 한 단계씩 진행하고, 화면 아래 자막에 단계 번호와 설명이 보입니다.

| 단계 | 하는 일 | 말할 것 |
| --- | --- | --- |
| 1 기업 찾기 | 검색창에 초성 'ㅅㅅㅈㅈ' 입력 | 초성만 쳐도 삼성전자가 나온다 |
| 2 보고서 고르기 | 현재 보고서를 '반기보고서 (2026.06)'로 바꾸면 전년 동기 '반기보고서 (2025.06)'가 짝지어짐 | 현재 보고서만 고르면 비교할 보고서를 알아서 찾는다 |
| 3 비교할 수 있는지 확인 | 기간·재무제표가 맞는지 확인한 결과 | 맞지 않으면 분석하지 않는다 |
| 4 핵심 3줄 | 분석 실행 → 결과 요약 | 줄마다 근거가 붙는다 |
| 5 재무 수치 | 계정별 증감 표 | 증감은 AI가 아니라 코드가 계산한다 |
| 6 AI 에이전트 | 재무 수치 탭(재무상태표)에서 '이익잉여금이 뭐야?' 질문 | 쉬운 말 풀이와 이 회사 숫자, 투자 조언은 하지 않는다 |
| 7 공시 분석 · 한 문단 요약 | AI 창을 닫고 공시 분석 탭의 한 문단 요약(근거를 확인 못 하면 '검토 필요' 자리) | 두 보고서 사이 1년을 한 문단으로 |
| 8 공시 분석 · 이 기간 타임라인 | 타임라인을 펼쳐 통째로 강조(머리가 화면 위쪽) | 언제 무엇을 했는지, 줄마다 근거가 붙고 공시는 원문으로 바로 열린다(보고서 문단·재무 수치 근거는 원문 탭·이름으로 보인다) |
| 9 공시 분석 · 이 기간에 한 일 | 타임라인을 접고 첫 활동 카드 강조. 첫 카드에 AI 전망이 없을 수 있다(반기 쌍은 '구글 EMADA 라이선스' 카드). 그때는 말로 보완한다. 화면으로 보여 주려면(선택) 10단계까지 마친 뒤 `Esc`로 직접 조작해 공시 분석 탭에서 'AI 전망 · 공시 사실 아님'이 붙은 카드(반기 쌍은 '관계사 회계처리 행정소송')를 가리킨다. `Esc` 뒤에는 자동 진행으로 돌아가지 않는다 | 공시에 적힌 사실은 원문 위치와 함께, 앞으로 확인할 점은 따로 |
| 10 원문 비교 | 원문 탭 바뀐 곳을 우선순위 순으로 → 목록 '더 보기' → '수정 · II. 사업의 내용 > 7. 기타 참고사항' → '원문 비교' 창 | 이전·현재 문단을 나란히, 바뀐 낱말에 밑줄 |

마지막 단계 뒤 `Space` → '시연 끝' → `Space`를 한 번 더 누르면 앱 화면이 닫히고 노트북 뚜껑이 닫히며 두 보고서 장이 나타납니다. 정리한 뒤 `Space`로 Q&A 장으로 갑니다.

## 4. 시연 중에 생길 수 있는 일

| 상황 | 화면 | 할 일 |
| --- | --- | --- |
| 4단계에서 새 분석이 실패하거나 90초를 넘김 | 기업 화면으로 돌아가 '이미 분석한 비교'의 결과가 열린다 | 그대로 진행한다(맨 위에 '이전 분석 방식' 띠가 보일 수 있다) |
| 단계가 실패 | 자막에 사유와 'Space로 다음 단계로 넘어가요' | `Space`로 다음 단계 |
| 공시 분석이 늦음(7단계) | 불러오는 그림이 최대 60초, 넘거나 오류면 '공시 분석을 이번에는 불러오지 못했어요' | `Space`로 다음 단계(전날 '공시 분석 탭 데우기'를 하면 바로 열린다) |
| AI가 답하지 못함(6단계) | 'AI가 이번에는 답하지 못했어요' | `Space`로 다음 단계(7단계에서 AI 창을 닫고 넘어간다) |
| 직접 보여 주고 싶다 | 시연 화면에서 `Esc` → 오른쪽 아래 '발표로 돌아가기' 버튼만 남는다 | 직접 조작한 뒤 버튼을 누르면 두 보고서 장으로 간다. 전체화면이면 Esc로 전체화면이 풀리니 `F`로 다시 켠다 |
| 화면이 새로 고쳐짐 | 자막이 'N단계부터 이어서 해요' | `Space`로 이어 간다 |

- 발표 페이지(HTML)는 배포하면 바로 새 것이 보입니다. PPTX·이미지처럼 HTML이 아닌 파일은 Cloudflare가 브라우저 캐시를 4시간으로 정해, 같은 이름으로 다시 만든 파일은 최대 4시간 옛 것이 받아질 수 있습니다. 새 PPTX를 바로 받으려면 주소 끝에 `?v=1118`처럼 아무 값이나 붙입니다.
- 앱만 따로 열어 시연하려면 주소에 `?demo`를 붙입니다. `?demo=5`처럼 번호를 주면 그 단계부터 시작합니다.
- 리허설에서 실제 한글 입력으로 첫 화면 검색도 한 번 쳐 봅니다. 한 글자를 조합하는 도중에 0.3초 넘게 멈추면 그 글자의 조합이 끊길 수 있습니다(#988의 남은 한계).

## 5. 쉬는 동안: 대기 화면(Windows)

발표·시연 사이에 노트북을 쓰지 않을 때 `https://dart-insight.shinhanacademy.co.kr/easter/idle.html`을 띄워 둡니다. 장면 5개(소개, 문제, 코드가 계산한 숫자, 원문 위치가 붙은 문장, 서비스 주소 QR)가 약 40초마다 반복됩니다.

1. 발표 페이지와 다른 창(Edge나 Chrome의 새 창, `Ctrl+N`)에서 위 주소를 열고 `F11`로 전체 화면으로 둔다. 발표로 돌아갈 때는 `Alt+Tab`으로 발표 창을 고른다.
2. 지나가던 사람이 화면을 누르거나 아무 키나 누르면 같은 탭에서 메인 페이지로 옮겨 가 직접 써 볼 수 있다(전체 화면은 그대로다).
   - `F11`·`Esc`·`Alt+Tab`·`Ctrl`·`Win` 같은 화면 조작 키는 세지 않는다.
   - 마우스를 움직이면 커서가 잠깐 보였다 사라진다.
3. 앱에서 2분 동안 아무 조작(마우스·키·터치·휠)이 없으면 대기 화면으로 돌아온다. 15초 전부터 아래 가운데에 'N초 뒤 처음 화면으로 돌아가요'가 뜨고, 화면을 움직이거나 '계속 쓰기'를 누르면 다시 센다.
   - 대기 화면에서 들어온 탭(주소 `/?kiosk`)에서만 이렇게 된다. 발표 창, 다른 방문자, 시연 자동 진행에는 켜지지 않는다.
   - 대기 화면에 돌아오면 그 탭의 앱 기록(sessionStorage의 `dart-insight:` 키)을 지워 다음 사람이 처음부터 시작한다. 최근 본 기업(localStorage)은 남는다.
   - 리허설 때는 `/?kiosk=30`처럼 초를 줄여 확인한다(30초~1시간). 그 탭에서 끄려면 `/?kiosk=off`.
   - 바로 대기 화면으로 돌리려면 `F11`로 전체 화면을 잠깐 풀고 주소창에 대기 화면 주소를 연다.
   - 같은 탭에서는 왼쪽 아래에 '따라 해 보기' 카드가 뜬다. 기업 찾기 → 보고서 고르기 → 비교 확인 → 분석 → 결과 보기 중 지금 할 일을 알려 주고, '어디예요?'를 누르면 누를 곳에 테두리를 그린다. 결과 화면에서는 재무 수치·공시 분석·바뀐 문장·AI 에이전트를 해 볼 일로 두고 해 본 일에 표시한다.
   - 카드는 ×로 접을 수 있고(왼쪽 아래 '따라 해 보기' 버튼으로 다시 편다), '처음부터'를 누르면 첫 화면으로 간다. 대기 화면에 돌아오면 다음 사람에게 다시 펼쳐진다. 다른 창에서 카드만 보려면 `/?guide`, 끄려면 `/?guide=off`.
4. 열려 있는 동안 브라우저가 화면 꺼짐을 막는다. 화면 위에 '화면 꺼짐 방지를 켜지 못했어요'가 뜨면 설정 > 시스템 > 전원(Windows 10은 '전원 및 절전')에서 화면 끄기를 '안 함'으로 바꾼다.
5. 리허설 때 띄워 두고 10분쯤 그대로 두어 화면이 꺼지거나 잠기지 않는지 본다. 학원 PC에 잠금 정책이 걸려 있으면 브라우저가 막지 못할 수 있다.
6. 알림이 화면을 가리지 않게 Windows 알림의 '방해 금지'를 켠다.

- 인터넷이 없어도 돈다. 미리 위 주소에서 `Ctrl+S`로 'HTML만' 저장해 두면, 저장한 파일을 두 번 눌러 연다(글꼴·그림이 파일 안에 들어 있다). 저장한 파일에서 누르면 실서비스 주소가 열리니, 써 보게 하려면 인터넷이 필요하다(돌아올 때는 실서비스의 대기 화면으로 온다).
- 숫자·문장은 시연 쌍(분석 214) 결과를 옮긴 것이다. 문구를 고치면 `python3 scripts/inline_idle_fonts.py`로 글꼴을 다시 담는다(빠진 글자는 맑은 고딕으로 보인다).
