> 같은 회사의 정기보고서 두 개를 비교해, 바뀐 숫자와 문장을 원문 위치와 함께 보여 주는 서비스입니다. 투자 조언이 아닙니다.

- **이 문서는 `scripts/generate_presentation_pptx.py`가 만드는 PPTX(23장)의 발표자 노트와 같습니다.** PPTX를 다시 만들면 이 문서도 같이 맞춥니다.
- 웹 발표 페이지(`frontend/public/easter/three-weeks.html`, 12장)의 대본은 페이지의 '발표 대본(N)' 사이드바에 있습니다.
- 대본 형식: ① 여는 질문 → ② 쉬운 설명 → ③ 화면 가리키기 → ④ 마무리 한마디. 장마다 30~45초.
