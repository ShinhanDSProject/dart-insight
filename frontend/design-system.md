# dart-insight 디자인 시스템 및 UI 디자인 가이드

dart-insight의 공시 및 기업 비교 서비스를 위한 UI 구성과 디자인 시스템 기준을 정의한다.

---

# 1. 디자인 시스템 목적

dart-insight는 기업의 공시 및 관련 데이터를 비교하여 사용자가 기업 간 차이와 주요 정보를 쉽게 확인할 수 있도록 구성한다.

디자인 시스템은 다음을 기준으로 한다.

- 전체 화면의 디자인 일관성 유지
- 기업 간 비교가 쉽게 보이는 UI 구성
- 공시 정보를 빠르게 확인할 수 있는 정보 구조
- 데이터와 차트의 가독성 확보
- Figma 디자인과 실제 개발 화면의 일관성 유지

---

# 2. 화면 구성

dart-insight는 사용자의 서비스 이용 흐름에 따라 다음과 같이 구성한다.

```text
홈
 ↓
기업 선택 화면
 ↓
비교 설정 화면
 ↓
공시 비교 결과 화면
 ↓
공시 상세 화면
```

## 2-1. 홈

서비스에 처음 진입했을 때 사용하는 화면이다.

- 서비스 소개
- 기업 검색
- 공시 검색
- 최근 조회 기업
- 주요 공시

---

## 2-2. 기업 선택 화면

비교할 기업을 선택하는 화면이다.

- 기업 검색
- 기업 목록
- 기업명
- 기업 로고
- 기업 기본 정보
- 기업 선택
- 비교 대상 추가
- 비교 대상 삭제

---

## 2-3. 비교 설정 화면

선택한 기업과 비교 조건을 설정하는 화면이다.

- 비교 기업
- 공시 유형 선택
- 기간 선택
- 산업 / 업종 선택
- 정렬 기준 선택
- 비교하기

---

## 2-4. 공시 비교 결과 화면

선택한 기업의 공시 및 주요 데이터를 비교하는 핵심 화면이다.

- 비교 대상

### 항목 비교
- 비교 항목
- 기업별 수치
- 전년 대비 변화
- 증감률
- 차이점 강조

### 공시 요약
- 핵심 내용
- 주요 수치
- 주요 변경 사항
- 중요도

### 비교 결과

- 차이점

# 3. 기본 디자인 시스템

## 3-1. 글꼴

- 글꼴 종류
- 제목
- 본문
- 설명 / 캡션
- 숫자 / 금액

- 정보의 중요도에 따라 글자 크기와 굵기를 구분한다.

# 6. 차트 및 데이터 시각화

## 6-1. 차트 종류

### 막대그래프
기업별 수치를 비교할 때 사용한다.

예:
- 기업별 매출액
- 영업이익
- 당기순이익
- 주요 지표 비교

### 원그래프 / 파이차트
전체에서 각 항목이 차지하는 비중을 보여줄 때 사용한다.

예:
- 자산 구성
- 부채 구성
- 특정 항목 구성 비율

### 방사형 그래프
여러 항목을 동시에 비교하거나 기업별 특징을 비교할 때 사용한다.

예:
- 주요 재무 지표 비교
- 기업별 지표 특성 비교

---

## 6-2. 데이터 시각화 기준

| 데이터 | 시각화 |
|---|---|
| 기업별 비교 | 막대그래프 |
| 기간별 변화 | 데이터 비교 UI |
| 증감률 비교 | 막대그래프 |
| 주요 지표 비교 | 방사형 그래프 |
| 비중 비교 | 원그래프 / 파이차트 |
| 상세 수치 | 테이블 |
| 공시 정보 | 리스트 / 테이블 |

### 적용 기준

- 기업 간 비교 → 막대그래프 우선
- 여러 지표 동시 비교 → 방사형 그래프
- 전체 대비 비중 → 원그래프 / 파이차트
- 차트와 실제 데이터 수치를 일치시킨다.
- 필요한 경우 실제 수치를 함께 표시한다.
- 데이터가 없는 경우 차트 대신 데이터 없음 상태를 표시한다.

# 12. 최종 UI 적용 기준

- 화면 흐름에 따라 UI를 구성한다.
- 동일한 컴포넌트를 반복해서 재사용한다.
- 기업 비교 시 동일한 위치에 동일한 항목을 배치한다.
- 공시 정보와 재무 데이터를 구분한다.
- 차트와 실제 데이터 수치를 일치시킨다.
- 상승 / 하락 표현을 일관되게 적용한다.
- 로딩 / 오류 / 데이터 없음 상태를 정의한다.
- Figma와 실제 개발 화면의 컴포넌트 구조를 일치시킨다.
- 사용자가 기업 선택부터 비교 결과까지 자연스럽게 이동할 수 있도록 구성한다.
